# Fermata CV — 디자인 가이드라인

> **확정 사항 (2026-09)**
> - 디자인 포맷은 **에디토리얼형 1종으로 고정**한다. 절제형·그리드형 변형은 더 이상 사용하지 않는다.
> - 언어는 **영어 단일**로 고정한다. 데이터 구조에서 `{en, ko}` 같은 다국어 객체를 쓰지 않고 평문 문자열을 쓴다.
> - 다국어 지원이 다시 필요해지면, 데이터 구조에 언어 키를 다시 추가하고 템플릿의 필드 접근부(`p.name` 등)를 `p.name[lang]` 형태로 되돌린다 — 과거 버전이 이 문서의 이전 리비전과 대화 기록에 남아 있다.

모든 수치는 이 문서를 기준으로 한다. 템플릿에서 임의 값을 쓰지 않는다.

---

## 1. 서체

| 역할 | 서체 | 이유 |
|---|---|---|
| 본문·제목 (한글+라틴) | **Pretendard** | 한글과 라틴이 한 가족이라 두 언어 PDF의 인상이 어긋나지 않는다 |
| 연도·마이크로 라벨 | **IBM Plex Mono** | 숫자 폭이 고정이라 연도가 세로로 정렬된다. 문서의 유일한 성격 요소 |

세리프는 쓰지 않는다. 한글에 대응하는 디스플레이 세리프가 없어 두 언어판의 격이 달라진다.

### 굵기
Pretendard 300 / 400 / 500 / 600 — 네 단계만 사용
Plex Mono 400 / 500

---

## 2. 타입 스케일

| 토큰 | 크기 | 용도 |
|---|---|---|
| `display` | 28pt (EN) / 26pt (KO) | 이름 |
| `h1` | 8.4pt | 섹션 제목 |
| `body-lg` | 9.6pt | 항목 제목 (기관명·곡명·콩쿠르명) |
| `body` | 8.4pt | 부가 설명 |
| `caption` | 7.6pt | 연락처, 연도 |
| `micro` | 6.4pt | eyebrow, 마이크로 라벨, 각주 |

여섯 단계 이상 쓰지 않는다.

---

## 3. 자간 (가장 중요)

한글과 라틴에 같은 값을 쓰면 한쪽이 반드시 어색해진다. 반드시 분리한다.

| 요소 | 라틴 | 한글 |
|---|---|---|
| 이름 (display) | −0.022em | −0.042em |
| 섹션 제목 | +0.04em (대문자) | −0.01em |
| 항목 제목 | −0.011em | −0.022em |
| 부가 설명 | −0.004em | −0.014em |
| eyebrow·마이크로 | +0.22em | +0.12em |
| 악기명 (대문자) | +0.2em | +0.1em |

**원칙**: 크기가 클수록 조이고, 작을수록 벌린다. 한글은 라틴보다 항상 0.01em 더 조인다.

섹션 제목을 과하게 벌리지 않는다. 회색 잔글씨로 흘려보내지 말고 본문보다 진한 색으로 세운다.

---

## 4. 색

| 토큰 | 값 | 용도 |
|---|---|---|
| `ink` | #16140F | 이름, 섹션 제목, 항목 제목, 콩쿠르 결과 |
| `body` | #45403A | — |
| `muted` | #837C73 | 부가 설명, 연락처 |
| `faint` | #B4ADA3 | 연도, 구분자, 각주 |
| `rule` | #E4DFD8 | 헤어라인 |
| `rule-strong` | #16140F | 헤더 하단 |
| `photo-bg` | #EFECE7 | 사진 자리 |

색은 다섯 단계까지. 강조색은 쓰지 않는다.

---

## 5. 간격 (3pt 배수)

| 토큰 | 값 |
|---|---|
| 페이지 여백 | 상 20mm / 좌우 19mm / 하 15mm |
| 사진 → 텍스트 | 7mm |
| 헤더 → 구분선 | 6mm |
| 섹션 사이 | 15pt |
| 섹션 제목 → 내용 | 7pt |
| 항목 사이 | 7.5pt |
| 항목 제목 → 설명 | 2pt |

---

## 6. 헤더

- 사진 **좌측**, 25 × 33mm (3:4 고정, `object-fit: cover`, `object-position: center 20%`)
- 텍스트 블록 높이를 사진 높이에 맞춘다. 두 요소의 하단이 같은 선에서 끝나야 한다
- 구성: eyebrow → 이름 → 악기 → 연락처
- 헤더 아래 0.7pt 진한 구분선 하나. 이 선이 문서의 기준선

---

## 7. 섹션별 표현 형식

**정보의 성격이 다르면 형식도 달라야 한다.** 모든 섹션을 같은 나열로 두지 않는다.

| 섹션 | 형식 | 이유 |
|---|---|---|
| 학력·사사 | **스택형** — 기관명 크게, 학위·사사 교수를 별도 줄로 | 건수가 적고 무게가 크다. 사사 교수는 클래식 CV의 핵심 정보라 마이크로 라벨을 붙여 독립시킨다 |
| 콩쿠르 | **결과 정렬형** — 연도 / 대회명 / **결과 우측 정렬** | 심사자가 제일 먼저 보는 건 결과다. 우측에 세로로 정렬해 한눈에 훑게 한다 |
| 연주 | **연도 그룹형** — 연도를 그룹 헤더로 묶고 곡명 중심 | 건수가 많다. 행마다 연도를 반복하면 시선이 분산된다 |
| 마스터클래스 | **2단 압축형** — 한 줄에 두 건 | 개별 무게가 낮다. 촘촘하게 묶어 문서 하단의 밀도를 조절한다 |
| 레퍼토리 | **인라인형** — 구분점으로 연결 | 목록이 아니라 범위를 보여주는 정보다 |

---

## 8. 정렬 규칙

- 연도 칼럼 폭 54pt 고정, Plex Mono 사용 → 자릿수가 달라도 세로선이 흔들리지 않는다
- 모든 항목 텍스트의 좌측 기준선은 하나로 통일
- 콩쿠르 결과만 우측 정렬. 그 외 우측 정렬 금지
- 구분자는 본문보다 두 단계 연하게 (`faint`)

---

## 9. 검증 표시

- ● 기관 검증 / ○ 동료 확인, 6pt, `faint`, 제목 뒤 3pt 간격
- 각주 1줄로 설명. 로고·QR 등은 넣지 않는다
- 하단 중앙 프로필 주소는 6.2pt `faint` — 유일한 브랜딩

---

## 10. 금지

- 강조색, 배경 박스, 아이콘, 진행바, 별점
- 6단계를 넘는 타입 스케일
- 섹션 제목을 회색 잔글씨로 처리하는 것
- 한글과 라틴에 같은 자간을 쓰는 것
- 템플릿 2종 이상 제공 (선택지가 늘면 사용자가 고르지 못한다)
